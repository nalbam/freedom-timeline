# freedom-timeline

경제적 자유(FIRE) 달성 시점을 시뮬레이션하는 정적 웹앱입니다.
가족 구성원의 생년월일과 자산·소득·지출·수익률·인플레이션 등을 입력하면 즉시 계산되어
결과 카드와 그래프로 확인할 수 있습니다.

## 주요 기능

- **경제적 자유 시점 예측** — 순자산이 목표 자산(지출 ÷ 인출률)을 넘는 나이와, 노후에 자산이 바닥나는 고갈 나이를 계산
- **가족 단위 시뮬레이션** — 구성원 나이에 따라 자녀 교육비 구간을 자동 반영
- **현실적 가정** — 은퇴 후 지출 비율, 연금 물가연동, 주택·상속 등 일회성 이벤트
- **몬테카를로 분석** — 수익률 변동성을 반영한 자산 유지 성공 확률 + P10/P50/P90 분위수
- **표시 전환** — 오늘 가치 / 미래 가치(명목) 토글, 다크·라이트 테마

## 실행 방법

1. 저장소를 클론합니다.
2. 브라우저에서 `docs/index.html` 파일을 직접 엽니다. (빌드 단계 없음)
3. 입력값은 브라우저 `localStorage`에 자동 저장/복원됩니다.

## GitHub Pages 배포

`/docs` 폴더를 GitHub Pages 루트로 사용합니다.
저장소 **Settings → Pages**에서 Source를 `main` 브랜치의 `/docs` 폴더로 지정하면 배포됩니다.
